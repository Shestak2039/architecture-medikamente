# Задание 2. Проектирование решения

## Что изменилось

**Системы Privacy by Design.** Сотрудники входят через IAM с MFA, доступ выдается по ролям и атрибутам, медкарту видит только лечащий врач. Согласия пациентов и запросы на удаление обрабатывает отдельная система. Лаборатория и партнеры получают токен пациента вместо ФИО. Ключи шифрования хранятся отдельно от данных. Каталог данных ведет теги и lineage и проверяет релизы на работу с тегированными полями. Доступ к ПДн пишется в аудит с алертами ответственному за ПДн, DLP не дает вынести медданные через почту и носители.

**Внутри медицинской системы.** Внешние системы и приложения ходят в нее только через API-шлюз, который отдает поля по политике, и пациент видит только свои данные. ПДн пациента хранятся в одном реестре, остальные части системы хранят только ID. В 1С уходят только услуга и сумма.

**Аналитическая платформа.** Данные приходят из медицинской системы уже псевдонимизированными, без ФИО и контактов. Внутри они проходят сырую и обработанную зоны и попадают в витрины. BI и ML работают только с обезличенными данными на сервере.

**Где разворачивается.** Все системы на своих серверах в РФ, это требование 152-ФЗ.
